# Lab-First FPGA workspace

[Scaffold guide](../docs/en/scaffold.md) · [Hướng dẫn khung RTL](../docs/vi/scaffold.md)

This directory contains the [controller RTL](experiment-controller/README.md),
[instrument interfaces](instrument/README.md) and
[simulation benches](simulation/README.md). The Hardware Service owns
`FpgaTransport` and the private transport boundary. The
[scaffold guide](../docs/en/scaffold.md) records the control behavior, device
targets and evidence required for physical deployment.
